# PF2E Eliott Tools

Личный модуль для Pathfinder 2e в Foundry VTT: небольшие фиксы, автоматизация и готовые компендиумы для наших игр.

## Что делает модуль

- Исправляет `Oath of the Defender`: сопротивление союзников в ауре применяется только к самому большому подходящему инстансу урона, как написано в фите.
- Добавляет готовый компендиум `Hero Action Deck` с картами действий героя.
- Добавляет русский компендиум `Critical Hit/Fumble Deck RU` и перенаправляет броски стандартной крит-колоды PF2e на русские записи журнала.
- Добавляет опциональную автоматизацию `Shields of the Spirit`: когда атакующее действие с признаком `attack` направлено на цель с этим эффектом, модуль автоматически бросает ответный spirit-урон по атакующему.
- Добавляет боевые улучшения: автосброс целей при смене хода и круговой HP-индикатор в боевом трекере.
- Добавляет мастеру кнопку ▶/⏸ в стандартное окно PF2e «Время мира»: одна игровая секунда за одну реальную.
- Автоматически накладывает тошноту 1 при критическом промахе безоружной атакой по доспеху из холодного железа, серебра или суверенной стали, если у атакующего есть нужная уязвимость.

## Материалы доспехов и критические промахи

В настройках модуля → «Материалы доспехов» есть галочка «Включить эффекты материалов доспеха при критическом промахе» (включена по умолчанию, действует сразу для всего мира).

| Материал надетого доспеха | Уязвимость атакующего | Результат критического промаха безоружной атакой |
| --- | --- | --- |
| [Холодное железо](https://2e.aonprd.com/Equipment.aspx?ID=2798) | Холодное железо | Тошнота 1 |
| [Серебро](https://2e.aonprd.com/Equipment.aspx?ID=2803) | Серебро | Тошнота 1 |
| [Суверенная сталь](https://2e.aonprd.com/Equipment.aspx?ID=777) | Холодное железо | Тошнота 1 |

Материал должен быть выбран в поле материала самого надетого доспеха, а у атакующего — указана уязвимость в листе. Название предмета, признак «нечестивый», тип «демон» или исключение из сопротивления не заменяют уязвимость. Перед броском нужно выбрать цель, чтобы PF2e сохранил её и степень успеха в сообщении атаки. Учитывается итоговая степень успеха, а не только натуральная 1. Работает с безоружными Ударами персонажей и NPC, включая когти и укусы с признаком `unarmed`.

Все степени качества материала дают именно тошноту 1. Повторные промахи не складывают её и не уменьшают уже имеющуюся тошноту 2+. Используется штатное состояние PF2e с проверкой иммунитета. В чат отправляется сообщение с материалом, атакующим, целью и результатом: тошнота наложена, уже имеется или не наложена из-за иммунитета. Сообщение сохраняет аудиторию исходного броска, включая приватные и слепые броски, и содержит ссылку на правило. Эффект обрабатывает только активный GM, без таймеров и сканирования сцены. При отключении функции уже наложенная тошнота остаётся до обычного снятия.

Это автоматизация конкретного триггера критического промаха, а не всех свойств материалов: ношение вредного доспеха самим уязвимым существом, ауры абизия и урон сиккатита при захвате сюда не входят. У остальных материалов нет автоматически добавленного эффекта на такой промах. [Рассветное серебро (dawnsilver, прежний mithral)](https://2e.aonprd.com/Equipment.aspx?ID=2917) приравнено к серебру для урона; перенос тошноты на него неоднозначен, поэтому он не включён в автоматизацию.

После переброса, отменившего исходный критический промах, уже наложенную тошноту при необходимости снимает мастер: автоматизация не откатывает ранее применённые состояния.

Для проверки используйте копии существ на тестовой сцене:

1. Включите настройку автоматизации и обновите страницу после установки изменений.
2. Наденьте на защитника доспех с материалом «Серебро» (`silver`). На листе атакующего добавьте уязвимость «Серебро», например 5; убедитесь, что у него нет тошноты и иммунитета к ней.
3. Выберите защитника целью и сделайте по нему Удар кулаком, когтями или укусом с признаком «Безоружное» (`unarmed`). Для быстрого получения критического промаха можно добавить большой временный штраф к броску в диалоге, например −100. Проверьте именно итог «Критический провал»: натуральная 20 может повысить его до обычного провала.
4. У атакующего должна появиться тошнота 1, а в чате — объяснение с материалом «Серебро».
5. Снимите тошноту, смените материал надетого доспеха на «Суверенная сталь» (`sovereign-steel`, стандартное качество), а уязвимость атакующего — на «Холодное железо». Повторите атаку: результат тот же, в чате указана суверенная сталь.
6. Проверьте отсутствие эффекта при обычном промахе, оружейной атаке, снятом доспехе, удалённой уязвимости и выключенной настройке. При иммунитете или уже имеющейся тошноте 2 чат объясняет отсутствие нового состояния, а её значение не меняется.

## Автоматический ход времени

Откройте «Время мира» и нажмите «Запустить время». Кнопка «Пауза» останавливает отсчёт. Закрытие окна не останавливает часы; ручные кнопки продвижения времени работают как обычно.

В настройках модуля, в разделе «Время мира», мастер может отключить «Автоматический ход времени». Кнопка сразу исчезает, таймер останавливается. Повторное включение возвращает кнопку и прежнее состояние запуска, без добавления времени, прошедшего при отключённой функции.

На паузе Foundry и пока есть начатый бой автоматический отсчёт приостанавливается и возобновляется после снятия паузы/завершения боя. Состояние запуска общее для всех мастеров и сохраняется при перезагрузке. Время продвигает только один активный мастер; без подключённого мастера часы не идут и пропущенное время при подключении не добавляется.

Меняется настоящее время мира Foundry, поэтому PF2e обрабатывает длительности эффектов и синхронизацию освещения так же, как при ручном продвижении времени.

## Настройки

В стандартных настройках модуля можно отдельно включать и выключать:

- фикс `Oath of the Defender`;
- русский оверрайд крит-колоды;
- автоматизацию `Shields of the Spirit`.
- автосброс целей в конце хода;
- HP-кольцо в боевом трекере.
- автоматический ход времени мира.
- эффекты материалов доспеха при критическом промахе.

Это нужно, чтобы быстро отключить функционал, если PF2e позже добавит официальную поддержку или если конкретная игра хочет вести правило вручную.

Настройки разделены заголовками по категориям. Автосброс целей клиентский: каждый игрок может отключить его у себя, но по умолчанию он включен для всех. HP-кольцо настраивается мастером для мира.

## Важное замечание о переводе

Русский текст `Critical Hit/Fumble Deck RU` переведен через ИИ и должен быть проверен мастером перед использованием.

## Релиз

Для публикации новой версии:

1. Обновить `version` в `module.json`.
2. Закоммитить изменения и отправить их в GitHub.
3. Создать и отправить тег вида `vX.Y.Z`, например `v0.3.0`.
4. GitHub Actions соберет `module.json` и `pf2e-eliott-tools.zip`, затем опубликует release.

В pack-папках в git должны оставаться только данные готовых компендиумов:

```text
packs/*/*.ldb
packs/*/CURRENT
packs/*/MANIFEST-*
```

Временные файлы Foundry/LevelDB не нужны в репозитории:

```text
packs/*/LOCK
packs/*/LOG
packs/*/LOG.old
packs/*/*.log
```

`CURRENT` и `MANIFEST-*` — обязательные части базы, а не временные логи. Foundry может менять их при открытии мира даже без редактирования содержимого. Такие изменения не нужно добавлять в коммит с изменениями кода. При обновлении самих компендиумов сохраняйте согласованный снимок всей базы после закрытия мира; не откатывайте отдельные файлы открытой базы.

Текущая сборка релиза упаковывает `packs/` прямо из Git. Исключать `CURRENT` и `MANIFEST-*` из репозитория по отдельности нельзя. Чтобы убрать этот шум полностью, нужно перейти на JSON/YAML-исходники обоих компендиумов и сборку LevelDB при выпуске релиза — [рекомендованный Foundry подход](https://foundryvtt.com/article/v11-leveldb-packs/).
