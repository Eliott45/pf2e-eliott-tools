# PF2E Eliott Tools

Личный модуль для Pathfinder 2e в Foundry VTT: небольшие фиксы, автоматизация и готовые компендиумы для наших игр.

## Что делает модуль

- Исправляет `Oath of the Defender`: сопротивление союзников в ауре применяется только к самому большому подходящему инстансу урона, как написано в фите.
- Добавляет готовый компендиум `Hero Action Deck` с картами действий героя.
- Добавляет русский компендиум `Critical Hit/Fumble Deck RU` и перенаправляет броски стандартной крит-колоды PF2e на русские записи журнала.
- Добавляет опциональную автоматизацию `Shields of the Spirit`: когда атакующее действие с признаком `attack` направлено на цель с этим эффектом, модуль автоматически бросает ответный spirit-урон по атакующему.
- Добавляет боевые улучшения: автосброс целей при смене хода и круговой HP-индикатор в боевом трекере.
- Добавляет мастеру кнопку ▶/⏸ в стандартное окно PF2e «Время мира»: одна игровая секунда за одну реальную.

## Автоматический ход времени

Откройте «Время мира» и нажмите «Запустить время». Кнопка «Пауза» останавливает отсчёт. Закрытие окна не останавливает часы; ручные кнопки продвижения времени работают как обычно.

В настройках модуля, в разделе «Время мира», мастер может отключить «Автоматический ход времени». Кнопка сразу исчезает, таймер останавливается. Повторное включение возвращает кнопку и прежнее состояние запуска, без добавления времени, прошедшего при отключённой функции.

На паузе Foundry и пока есть начатый бой автоматический отсчёт приостанавливается и возобновляется после снятия паузы/завершения боя. Состояние запуска общее для всех мастеров и сохраняется при перезагрузке. Время продвигает только один активный мастер; без подключённого мастера часы не идут и пропущенное время при подключении не добавляется.

Меняется настоящее время мира Foundry, поэтому PF2e обрабатывает длительности эффектов и синхронизацию освещения так же, как при ручном продвижении времени.

## Настройки

В стандартных настройках модуля можно отдельно включать и выключать:

- фикс `Oath of the Defender`;
- русский оверрайд крит-колоды;
- автоматизацию `Shields of the Spirit`.
- автосброс целей в конце хода;
- HP-кольцо в боевом трекере.
- автоматический ход времени мира.

Это нужно, чтобы быстро отключить функционал, если PF2e позже добавит официальную поддержку или если конкретная игра хочет вести правило вручную.

Настройки разделены заголовками по категориям. Автосброс целей клиентский: каждый игрок может отключить его у себя, но по умолчанию он включен для всех. HP-кольцо настраивается мастером для мира.

## Важное замечание о переводе

Русский текст `Critical Hit/Fumble Deck RU` переведен через ИИ и должен быть проверен мастером перед использованием.

## Релиз

Для публикации новой версии:

1. Обновить `version` в `module.json`.
2. Закоммитить изменения и отправить их в GitHub.
3. Создать и отправить тег вида `vX.Y.Z`, например `v0.3.0`.
4. GitHub Actions соберет `module.json` и `pf2e-eliott-tools.zip`, затем опубликует release.

В pack-папках в git должны оставаться только данные готовых компендиумов:

```text
packs/*/*.ldb
packs/*/CURRENT
packs/*/MANIFEST-*
```

Временные файлы Foundry/LevelDB не нужны в репозитории:

```text
packs/*/LOCK
packs/*/LOG
packs/*/LOG.old
packs/*/*.log
```

`CURRENT` и `MANIFEST-*` — обязательные части базы, а не временные логи. Foundry может менять их при открытии мира даже без редактирования содержимого. Такие изменения не нужно добавлять в коммит с изменениями кода. При обновлении самих компендиумов сохраняйте согласованный снимок всей базы после закрытия мира; не откатывайте отдельные файлы открытой базы.

Текущая сборка релиза упаковывает `packs/` прямо из Git. Исключать `CURRENT` и `MANIFEST-*` из репозитория по отдельности нельзя. Чтобы убрать этот шум полностью, нужно перейти на JSON/YAML-исходники обоих компендиумов и сборку LevelDB при выпуске релиза — [рекомендованный Foundry подход](https://foundryvtt.com/article/v11-leveldb-packs/).
