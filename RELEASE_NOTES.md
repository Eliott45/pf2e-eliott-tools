## PF2E Eliott Tools 0.5.7

- Добавлена **синхронизация выбора целей с Automated Animations**, в том числе для анимаций из PF2e Animation Macros: анимация области ждёт подтверждения в окне и получает выбранные цели.
- Галка **«Убрать шаблон после выбора»** передаётся анимации: область сохраняется до проигрывания эффекта, затем удаляется самой анимацией. При отмене выбора анимация продолжает работу с текущими целями, а шаблон остаётся.
- Если модуль анимаций уже удалил область, окно выбора целей остаётся открытым и сохраняет список существ. Выбранные цели можно подтвердить после исчезновения шаблона.
- Синхронизация включена по умолчанию и отключается каждым игроком отдельно в настройках модуля. Без Automated Animations выбор целей работает как прежде.

### После обновления

Перезапустите сервер Foundry, затем обновите страницы мастера и игроков. Для выбора целей по шаблону требуются **Foundry VTT 14 и PF2e 8**. Новая настройка называется «Синхронизация выбора целей с Automated Animations».
