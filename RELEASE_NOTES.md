## PF2E Eliott Tools 0.5.4

- Добавлена **Mythic Magic**: отдельная запись заклинаний, автоматическое повышение ранга, мифическое владение для атак и СЛ, расход мифических пунктов. Расчёт использует умственную характеристику и не подменяется классовой СЛ. Требуются Foundry 14 и PF2e 8.
- Исправлен **глоток чаши по чужой цели**: игрок запускает макрос, а подключённый мастер автоматически применяет эффект. Выдавать игроку права на цель не требуется.
- Добавлено обновление стандартных старых копий макроса чаши; ручные изменения копий в мире сохраняются.
- README сокращён, подробная инструкция по мифической магии вынесена в отдельный документ.
- Компендиум макросов собирается из актуальных исходников при выпуске релиза.

### После обновления

Перезапустите сервер Foundry, затем обновите страницы мастера и игроков. Если старая кнопка чаши всё ещё сообщает об отсутствии прав, импортируйте макрос заново из компендиума «Тауматург — макросы». Для применения глотка к чужой цели нужен подключённый мастер; лечение от осушения по-прежнему применяется из чата.
