# Мифическая магия

1. Добавьте персонажу черту **Mythic Magic / Мифическая магия** из компендиума PF2e.
2. На вкладке заклинаний нажмите **«+ Мифическая магия»**. Чтобы использовать существующую запись врождённой магии, нажмите звезду в её заголовке.
3. Перетащите выбранные заклинания в эту запись. Показывается только текущий ранг сотворения; он автоматически пересчитывается при изменении уровня персонажа. Кнопка поиска открывает стандартный браузер заклинаний PF2e.
4. В настройках мифической записи доступны только Интеллект, Мудрость и Харизма; владение закреплено как «Мифическое». Для заклинателя выберите характеристику его класса, для остальных — Харизму. При создании она копируется из первой подготовленной/спонтанной записи с умственной характеристикой, если такая есть. Сила, Ловкость, Телосложение и СЛ физического класса не используются для этой записи.
5. Кнопка сотворения расходует **1 мифический пункт**, а не обычную ячейку или дневное использование. При нуле пунктов сотворение блокируется. Количество доступных пунктов отображается в заголовке.

Общая магическая традиция для этой черты не задана: поле скрыто, браузер не ограничивается одной традицией, а атаки и СЛ записи не получают условия арканной, сакральной, оккультной или природной магии из её старых настроек. Сохранённая традиция существующей записи восстанавливается при отключении режима. В служебных данных карты заклинания PF2e по-прежнему выбирает первую традицию самого заклинания (или Arcane, если список пуст); модуль этот механизм не меняет.

Звезда отключает режим у выбранной записи. Общая настройка находится в разделе «Автоматизация заклинаний». Исходные заклинания и обычное владение не переписываются; удаление черты прекращает применение мифического владения. После установки новой версии перезапустите сервер Foundry, чтобы он перечитал список скриптов модуля, затем обновите страницу.

Выбор заклинаний по тексту черты проверяют игрок и мастер: до трёх заклинаний 1–2-го ранга, одно 3-го ранга с 14-го уровня и одно 4-го ранга с 20-го; ограничения времени сотворения и длительности также проверяются вручную. Режим не предназначен для другой черты **Mythic Casting** или отдельной системы мифических заклинаний. Мифическое владение применяется только к этой записи и не повышает общую СЛ класса/заклинаний для других способностей.

Ручная проверка в тестовом мире: персонаж 9-го уровня с Харизмой +4 без прочих модификаторов должен иметь 5-й ранг, атаку +23 и СЛ 33; на 10-м уровне ранг остаётся 5-м, на 11-м становится 6-м. Проверьте перетаскивание, карту заклинания в чате, повышение урона/области, расход пунктов, ноль пунктов и отключение режима. Автоматические тесты используют модель API PF2e и не заменяют проверку в работающем мире.
